# DELTA Website

Official website for DELTA - Discovering Econometrics: Learning Through Application at Notre Dame.

## Development

```bash
npm install
npm start
```

## Build and Deploy

```bash
# Build the production version
npm run build

# Upload to server
scp -r build/* root@159.65.173.202:/var/www/nddelta/
```

## Deployment

The website is hosted at https://nddelta.com
